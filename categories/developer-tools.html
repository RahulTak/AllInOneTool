Frequently Asked Questions about Developer Tools

Is formatted JSON or code sent to an external API? +

Never. Parsing, syntax highlighting, and minification happen directly inside your browser engine. It is completely safe for proprietary code and API keys.

What cryptographic hash algorithms are supported? +

Our Hash Generator supports MD5, SHA-1, SHA-256, SHA-384, and SHA-512 using the native browser Web Cryptography API.

Are generated UUIDs cryptographically random? +

Yes. UUID v4 strings are generated using crypto.getRandomValues() to guarantee collision-resistant pseudo-random identifiers.

Can I scan QR codes using my webcam? +

Yes. The QR Code Scanner can decode QR barcodes both from uploaded image files and via live webcam video feeds locally.
