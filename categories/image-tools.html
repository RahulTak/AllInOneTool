Frequently Asked Questions about Image Tools

Are my image files uploaded to a remote server? +

No. All image transformations, conversions, resizing, and compressions run 100% locally inside your browser using HTML5 Canvas and Web APIs. Your images are never transmitted over the internet.

What image file formats are supported? +

Our image tools support standard modern web formats including JPEG/JPG, PNG, WebP, SVG, GIF, ICO, TIFF, and EPS.

Is there a limit on file size or number of images? +

Because processing executes client-side on your own device, there are no artificial server paywalls, daily quotas, or queue limits. Performance is limited only by your computer memory.

Does image compression reduce visual image quality? +

You can choose between Low, Medium, and High compression modes to find the ideal balance between visual clarity and file size reduction for your website or app.
